# JVC TK-C750U reference

Late-90s JVC color CCTV box camera, made in Thailand by Victor Company of Japan.

## From the label

- Model: TK-C750U (U = US/NTSC version)
- Power: **AC 24 V, 60 Hz, 3.3 W**
- UL listed, commercial CCTV equipment

## My unit

- Came from a security-company install in a store (there's an old installer sticker on it)
- Lens: 2.8-12 mm, f/1.4, 1/3", CS mount, aspherical, auto-iris (has its own cable to the camera)
- Includes a white swivel wall bracket
- Untested when bought

## Back panel

**Power terminals 1 and 2 (AC24V~)**
The 24 V AC transformer's two wires go here. AC has no polarity, so either wire can go in either terminal.

**VIDEO OUT (BNC)**
The composite video output. It goes to the TV's yellow input through a BNC-to-RCA cable.

**DIP switches** (the little slide switches), one per row:

- **AES**: auto electronic shutter. Turn it on with a manual-iris lens so the camera controls exposure electronically. With an auto-iris lens like mine, the lens handles exposure, so this is usually off. Check the manual.
- **BLC**: backlight compensation. Brightens the subject when there's a bright window or light behind it.
- **ATW / AWB**: white balance. ATW (auto-tracking) adjusts continuously. AWB locks white balance when you press SET while pointed at something white.
- **INT / LL**: sync source. INT is internal timing. LL (line lock) locks timing to the 60 Hz power line, which is used when several cameras share a switcher. INT is fine for one camera.

**PHASE + / -**
Fine-tunes line-lock timing. Only matters in LL mode.

**SET / RESET buttons**
SET locks white balance in AWB mode. RESET returns settings to default (see the manual for the exact behavior).

**POWER LED**
Green when the camera has power.

## On the body

- **BF LOCK**: back-focus lock screw. Loosen it to slide the lens mount for sharper focus across the zoom range, then tighten.
- **DIGITAL** marking on the side: digital signal processing inside (a late-90s selling point), but the output is still analog.

## Settings I plan to start with

- AES off (the auto-iris lens handles exposure)
- BLC off
- ATW on
- INT sync
